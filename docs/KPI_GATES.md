# KPI gates

Do not optimize for raw visits.

## Before paid acquisition

- tutorial/first-action completion >= 70%
- first-session core-loop completion >= 60%
- D1 retention trend positive across two comparable cohorts
- math-task completion does not materially reduce session continuation
- social incidents improve continuation or return rate versus non-participants

## Monetization rollout

1. Cosmetics/status only.
2. Canary monetization prompts to a small eligible cohort.
3. Roll back if D1 retention falls >7% relative or if session continuation falls >8%.
4. Add convenience only after cosmetics demonstrate willingness to pay.

## Kill rule

Two well-instrumented iterations with no target-KPI improvement means reposition the mechanic; do not add content volume to hide a weak loop.
